# Módulo Python

Aplicação Streamlit da Gestão Comercial. A inicialização cria tabelas e índices sem remover dados existentes e ativa chaves estrangeiras em todas as conexões SQLite.

## Execução

Na pasta `python/`:

```bash
streamlit run app.py
```

A base SQLite é adequada para desenvolvimento e demonstração local. O arquivo `gestao_comercial.db` não deve ser versionado.
